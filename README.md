# ТОО «PSA» — лендинг

Одностраничный сайт ТОО «PSA», Полномочного органа Правительства Республики Казахстан в проектах СРП (Кашаган, Карачаганак, Дунга).

**Продакшен:** https://psa-landing-gold.vercel.app
**Репозиторий:** https://github.com/zhzhumabekov/psa-landing

## Стек

Обычный HTML5 + CSS (без препроцессоров и сборки) + vanilla JS. Сборочного шага нет — файлы отдаются как есть.

## Структура

```
psa-landing/
├── index.html   — разметка всех блоков страницы
├── styles.css   — стили; все цвета/шрифты/отступы вынесены в CSS-переменные в :root
└── script.js    — мобильное меню, модальные окна проектов, переключение языка, форма
```

## Локальный запуск

Собирать нечего — достаточно поднять любой статичный сервер в папке проекта:

```bash
cd psa-landing
python -m http.server 8080
# открыть http://localhost:8080
```

Или через Node:

```bash
npx serve .
```

Открыть `index.html` напрямую двойным кликом тоже работает, но локальный сервер надёжнее (некоторые браузеры режут `fetch`/шрифты с `file://`).

## Деплой на хостинг из Git

### Vercel (используется сейчас)

Проект уже создан в Vercel: `psa-landing` в команде `zhomart` (`projectId` и `orgId` лежат в `.vercel/project.json`, сам файл в `.gitignore` и в репозиторий не попадает).

**Чтобы включить автодеплой при каждом пуше в GitHub** (сейчас деплой запускался вручную через CLI, привязки репозитория к проекту ещё нет — это делается один раз через браузер, CLI для этого шага не подходит):

1. Открыть панель проекта: https://vercel.com/zhomart/psa-landing
2. **Settings → Git → Connect Git Repository**
3. Выбрать репозиторий `zhzhumabekov/psa-landing`, ветка `master`
4. Сохранить

После подключения:
- пуш в `master` → автоматический деплой в Production (обновляет https://psa-landing-gold.vercel.app)
- пуш в любую другую ветку или открытие Pull Request → отдельный Preview-деплой со своей ссылкой (Vercel оставит её в комментарии к PR)

**Ручной деплой** (без привязки к Git, как было сделано изначально):

```bash
npx vercel login      # один раз, вход через браузер
npx vercel --prod
```

### Альтернативы (если понадобится сменить хостинг)

**Netlify**
1. New site from Git → выбрать `zhzhumabekov/psa-landing`
2. Build command оставить пустым
3. Publish directory: `.`

**GitHub Pages**
1. В репозитории: Settings → Pages
2. Source: Deploy from a branch → `master` → `/ (root)`
3. Сайт появится на `https://zhzhumabekov.github.io/psa-landing/`

## Переменные окружения

Сайт статический, серверной логики и переменных окружения нет.

## Редактирование стиля

Все токены дизайн-системы (цвета, шрифты, отступы, радиусы, тени) — CSS-переменные в начале `styles.css` (`:root { ... }`). Чтобы поменять фирменный цвет или шрифт по всему сайту, достаточно поправить значение переменной в одном месте.
