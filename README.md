# ТОО «PSA» — сайт

Сайт ТОО «PSA», Полномочного органа Правительства Республики Казахстан в проектах СРП (Кашаган, Карачаганак, Дунга).

**Репозиторий:** https://github.com/zhzhumabekov/psa-landing

## Архитектура

Django-монолит с CMS **Wagtail 8.0** — один сервер отдаёт и разметку (через шаблонизатор), и статику, и админку. Весь контент — дерево страниц Wagtail. Отдельного статик-сервера для фронтенда нет, всё в `backend/`.

```
psa-landing/
├── PROJECT_NOTES.md   — рабочие заметки (для агента/разработчика, история решений)
└── backend/           — Django-проект, см. backend/README.md
    ├── venv/            — виртуальное окружение (не в git)
    ├── templates/
    │   ├── base.html      — общая шапка/меню/подвал для всех страниц
    │   ├── index.html     — главная: Hero, О компании, Проекты, Партнёры, Контакты
    │   ├── local_content.html, procurement.html, documents.html, news.html
    │   │                  — списки разделов, контент из БД
    │   ├── *_detail.html  — страница отдельной записи раздела
    ├── static/styles.css, static/script.js — стили и клиентский JS (меню, i18n, модалки, форма)
    └── content/          — приложение: модели страниц Wagtail + миграции
```

Главная `/` и четыре раздела: `/local-content/`, `/procurement/`, `/documents/`, `/news/` — у каждой записи раздела своя страница (`/news/<slug>/` и т.п.). Ссылки меню — в `base.html`, ведут между ними и на разделы главной (`/#about` и т.п.).

## Запуск

```bash
cd backend
./venv/Scripts/python.exe manage.py runserver 127.0.0.1:8000
```

Открыть http://127.0.0.1:8000/. Админка Wagtail — http://127.0.0.1:8000/admin/. Подробности (креды, схема, восстановление окружения) — в `backend/README.md`.

## Продакшен

Раньше сайт был статикой на Vercel (`https://psa-landing-gold.vercel.app`) — с переходом на Django-монолит эта связка больше не актуальна: Vercel хостит только статику, а не Python-приложения. Задеплоенная там версия — устаревший снапшот кода, никак не подключённый к текущему репозиторию.

Для реального хостинга этого проекта нужен Python-совместимый хостинг (Railway, Render, Fly.io, VPS и т.п.) — отдельная задача, ещё не решена. Значение `SECRET_KEY` и креды суперпользователя перед этим обязательно сменить (см. `backend/README.md`).

## Дизайн-система

Все цвета/шрифты/отступы — CSS-переменные в начале `backend/static/styles.css` (`:root { ... }`).
